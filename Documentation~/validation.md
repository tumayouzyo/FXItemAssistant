# 検証内容

Unity 2022.3.22f1／Built-in Render Pipeline／Windows DX11で確認。

- EditModeテスト17件成功。プリセット、1x・2x・8xの出力寸法・透明度・色、Solid背景、対象の隔離、外部ボーン、描画範囲、NPOT画像、圧縮、上書き時のGUID維持、連番、保存先検証、カスタム設定維持を確認。
- 通常メッシュ／SkinnedMeshの撮影と、256×256・1200×900・4096×4096 PNGの生成を確認。
- PlayモードでNDMF処理後のアバターと小物の撮影を確認。
- 他Object非表示をオフ→オンにした後、24方向から撮影して描画を確認。
- SceneビューのFOVを変更せずに、撮影用焦点距離を変更できることを確認。
- 倍率ドロップダウン、縦配置、プレビューとSceneビューのドラッグ同期を実画面で確認。

これらはEditor上の検証です。VRChatへのアップロード・実機のExpression Menu表示・Android実機の画質までは検証していません。テスト用のモデル・テクスチャ・画像・シーンは配布物に含めていません。
